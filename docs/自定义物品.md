# HubSuite 自定义物品

> HubSuite 采用服务端与客户端双端配套模式：服务端和每个玩家的客户端均需安装对应模组（`hubsuite` 与 `hubsuite-client`），自定义物品与方块在两端直接注册，客户端使用内置模型与贴图渲染。

## 物品与方块清单

| id | 名称 | 用途 | 获取 |
|---|---|---|---|
| `hubsuite:nether_string` | 地狱线 | 钓竿装配材料（耐烧灼，适配岩浆钓鱼） | 合成 |
| `hubsuite:wooden_fishing_bucket` | 木渔桶 | 钓饵收纳袋，容量 **64** | 合成 |
| `hubsuite:iron_fishing_bucket` | 铁渔桶 | 钓饵收纳袋，容量 **256** | 合成 |
| `hubsuite:diamond_fishing_bucket` | 钻石渔桶 | 钓饵收纳袋，容量 **1024** | 合成 |
| `hubsuite:assembly_table` | 钓竿装配台 | 装配与修补分层钓竿（仅限海岛服使用） | 合成 |

- 渔桶堆叠上限为 1。
- **钓饵由物品 tag 驱动**：任何加入 `#hubsuite:fishing_bait` 的物品均可作为钓饵并装入渔桶（支持原版或第三方模组物品）。

---

## 渔桶用法（与原版收纳袋一致）

- **装入**：在背包内用渔桶点击钓饵（左键全装、右键装 1 个），或拿钓饵点击渔桶；
- **取出**：空手右键点击渔桶，或拿渔桶右键点击空格子取出一组；
- **混装与消耗顺序**：支持多种钓饵混装，容量按总个数计算；放在副手钓鱼时按**栈（后进先出）**顺序消耗，同种钓饵再次装入可置顶；
- **栈顶环境校验**：当栈顶钓饵与当前钓鱼环境（水 / 岩浆）不匹配时，渔桶不加速、不减速、也不消耗任何钓饵；
- **模型与 Tooltip**：Tooltip 显示内容物总数/容量与前 3 种明细；模型按**空 / 有饵**两种状态切换（`hubsuite:<桶>` 与 `hubsuite:<桶>_bait`，不按饵种类区分）。

## 钓饵定义（数据驱动）

两个物品 tag 位于 `data/hubsuite/tags/item/`：

| tag | 作用 |
|---|---|
| `#hubsuite:fishing_bait` | 是否可装入渔桶并作为钓饵使用 |
| `#hubsuite:fishing_bait_nether` | 属于岩浆钓鱼专用族的钓饵（默认水生族不进此 tag） |

- **档次加速**：按物品稀有度（`COMMON` / `UNCOMMON` / `RARE` / `EPIC`）提供不同咬钩加速。
- **环境不匹配惩罚**：散放副手的钓饵若用错环境（普通饵下岩浆或地狱饵下水），等待速度按 `1 - familyMismatchPenalty` 降低（默认 0.40，即速度 ×0.6）且照常消耗；使用渔桶则安全跳过。

## 合成表

| 物品 / 方块 | 配方摆法 |
|---|---|
| `hubsuite:nether_string`（地狱线） | 上左右 3 块下界岩 + 中间 1 根线 + 下方 1 块黑曜石 |
| `hubsuite:wooden_fishing_bucket`（木渔桶） | 5 块任意木板摆成桶形（A A / A A / A） |
| `hubsuite:iron_fishing_bucket`（铁渔桶） | 5 块铁锭摆成桶形 |
| `hubsuite:diamond_fishing_bucket`（钻石渔桶） | 5 颗钻石摆成桶形 |
| `hubsuite:assembly_table`（钓竿装配台） | 上排 3 铁锭 + 中排左铁锭/中工作台/右钓竿 + 下排 3 任意木板 |

配方在玩家获得对应材料时自动解锁并在配方书显示。

## 资源与本地化位置

所有双端共用物品定义与资源均位于 `common/` 目录：
- 物品定义与创造模式标签页：`common/src/main/java/cn/dreamgary/hubsuite/item/`
- 物品模型、方块状态与贴图：`common/resources/assets/hubsuite/`
- 语言文件：`common/resources/assets/hubsuite/lang/zh_cn.json` 与 `en_us.json`
- 客户端钓竿分层渲染模型：`client/src/main/resources/assets/minecraft/items/fishing_rod.json` 与 `client/src/main/resources/assets/hubsuite/models/item/rod/`
