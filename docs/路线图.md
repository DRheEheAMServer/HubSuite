## 1. 版本里程碑

- **0.3.0**（`main`）：单端纯服务端正式版（多世界隔离 + 账号登录 + 空岛/海岛 + 任务）。
- **0.4.0-alpha.6**（存档线）：钓饵 tag 化、3 档渔桶、JEI 软依赖。
- **0.5.0-beta.1**（2026-10）：客户端开发完成 + 0.6 钓竿系统七步全部落地（装配台 / 铁砧升级 / 耐久断线 / 青金石附魔 / 岩浆钓鱼改看钩）。
- **0.6.0-beta.1**（2026-11）：经典空岛「虚月律」魔法一/二期 + 内置 5 格「虚月饰品栏」+ 8 种自定义钓饵 + Blockbench 3D 模型与 1:1 贴图 + JEI 虚月祭坛仪式插件 + Polymer 下线。
- **0.6.0-beta.2**（2026-11）：修复方块名称前缀、3D 模型物品栏/手持显示变换、祭坛/基座主手交互防弹回、创造栏/JEI 全量物品补全与二期 Tooltip；新增客户端轻量更新提示与经典空岛「虚月律」引导任务链。
- **下一步 → 0.6.0 正式版**：实机跑稳 `0.6.0-beta.2` 后合入 `main` 发布双端正式版；后续按需推进海岛渔获图鉴/探索事件与虚月律三期高阶内容。

## 2. 已完成能力清单

- [x] 多项目 Gradle 构建（根 = 服务端，`client/` = 客户端，`common/` = 共用契约与资源，各自独立指纹）
