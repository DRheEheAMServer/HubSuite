# HubSuite

> 把**一台** Minecraft 服务端，变成「大厅 + 多个互相独立的子服」的 Fabric 模组。

一个服务端进程，跑出大厅、生存、创造、空岛（+ 海岛）几个**完全隔离**的世界；自带账号登录、任务系统、钓鱼与钓竿装配、经典空岛「虚月律」魔法体系与内置饰品栏。

- 服务器端模组 + 配套客户端模组（包含自定义方块/物品、立体模型与饰品栏界面）
- 支持 **Minecraft 26.1.2** / Fabric / Java 25
- 开源协议：[MIT](LICENSE)

---

## 环境要求

| 项目 | 要求 |
|---|---|
| Minecraft | **26.1.2** |
| 服务端 | Fabric dedicated server（不支持 Paper / Spigot / Forge / NeoForge） |
| Fabric Loader | 0.19.5+ |
| Fabric API | 0.155.3+26.1.2 |
| Java | **25** |

> ⚠️ 26.1 起 Minecraft 使用官方 Mojang 名称且不再混淆代码，仅兼容针对 26.1.2 构建的 Fabric 模组。

## 安装

1. 从 [Releases](https://github.com/DRheEheAMServer/HubSuite/releases) 下载 `hubsuite-<版本>.jar`，放进服务端 `mods/`；
2. 同一份 Release 里的 `hubsuite-client-<版本>.jar`，放进**每个玩家**的客户端 `mods/`。

**客户端模组是必需的。** 本模组包含自定义方块与物品（钓竿部件、钓饵、渔桶、装配台、月华/虚月祭坛、法器与饰品等）、Blockbench 立体模型及饰品栏界面，玩家客户端需安装对应模组以正常进服与渲染。

其余依赖全是**软依赖**，缺了不影响启动，只少对应功能：

| jar | 作用 |
|---|---|
| HuskHomes（Fabric 版 4.11+，26.1.2 构建） | 家 / 传送点 / Tpa / Warp |
| Placeholder API | 让其它模组读到 `%hubsuite_...%` 占位符 |
| Fabric Permissions API + LuckPerms | 权限分级 |
| JEI | 全量合成配方、虚月祭坛 16 项仪式配方与玩法说明页查看 |

> 🔴 HuskHomes 必须使用 **Fabric 版、版本号带 26.1.2** 的构建。

首次启动会自动生成配置与各子服存档。控制台执行 `hub selftest` 验证安装是否正常。

`server.properties` 里不要写任何非 ASCII 字符（Java 按 ISO-8859-1 读，中文注释会导致启动失败）。建议 `online-mode=false`、`gamemode=adventure`、`allow-flight=true`、`spawn-protection=0`。

## 功能

### 子服与世界隔离

- 每个子服一个**完全独立的存档**：地形、背包、饰品栏、经验、成就、统计、游戏规则互不影响
- **新增子服 = 加一条 JSON 配置，不用写代码**
- 每个子服拥有自己的下界与末地，传送门自动改道，不串服
- 独立下界/末地、虚空式空岛下界、岩浆海下界

### 大厅与账号

- 假人大厅：真 `ServerPlayer` 走完整入服路径，不出现在 Tab、不计在线人数
- 点假人弹出**箱子式服务器选择界面**
- 26.1 原版对话框注册登录，密码**不进聊天、不进命令、不进日志**

### 空岛与海岛

- 空岛服 = 1 个大厅 + 2 个岛屿维度：经典空岛（网格方格）与海岛（自然生成的海洋世界），可同时拥有
- 自然小岛：带宝箱、刷怪笼、村庄房屋，位置与物资全在配置里
- 每个岛型有独立的岛型命令：`/island classic`、`/island ocean`

### 钓鱼与钓竿

- 海岛渔获按维度挂表：稀有度分级（common → legendary）+ **按群系分池**
- **岩浆钓鱼**：需要专用钩子与耐烧灼钓线，配独立岩浆渔获表
- **8 种自定义钓饵与 3 档渔桶**：水域 3 档、岩浆 3 档、寻宝钓饵（+3 幸运）与双生钓饵（45% 双倍上钩），搭配木/铁/钻石渔桶自动收纳与补饵
- **钓竿四层装配**：杆 / 线 / 钩 / 升级，在立体**装配台**上组装，可用铁砧升级、加青金石附魔，会磨损断线

### 经典空岛魔法「虚月律」

- **双能采集与淬炼**：月华祭坛吸收月光凝结月晶；在 `Y ≤ -48` 触发虚空侵蚀采集虚空结晶；强月光下过载淬炼炽月晶
- **虚月祭坛 16 项月相仪式**：虚月祭坛配合周围 8 座魔力基座，按月相与双能配方完成资源转化、生态重塑、拨月调时与法器锻造（支持在 JEI 中查看完整仪式配方与机制说明页）
- **实用法器与装置**：月华催生仪（范围内加速作物生长）、星月观星镜、月翼法杖、虚空建造杖等，支持水晶镶嵌供能

### 内置「虚月饰品栏」

- 内置 5 格类型化饰品栏（护符、戒指 I、戒指 II、披风、护腕），支持按 `B` 键、点击背包左上角 `✦` 按钮或执行 `/trinket` 打开，并支持潜行右键快捷穿戴
- **5 件功能饰品**：虚空护符、虚空护腕（+交互距离）、月华脚环（+跨步高度与缓降减伤）、虚空锚点披风（`Y ≤ -55` 虚空救援）、月光虹吸戒（夜间月光充能）
- **1:1 平衡共鸣**：月系与虚空系饰品按 1:1 比例佩戴时触发平衡共鸣，法器与饰品魔力消耗降低 25%
- **多世界隔离**：饰品栏存档按子服完全隔离，切换子服不会串装

### 任务与权限

- 内置任务：里程碑 / 物资交付 / 每日三类，配置驱动，进度按玩家存
- 权限三级降级：LuckPerms → fabric-permissions-api → 原版 OP；创造服屏蔽 40+ 条作弊指令

## 常用命令

```text
/menu                       打开服务器选择界面
/hub                        回大厅
/hub <子服>                 直达某个子服
/hub list                   列出所有子服与在线人数
/hub where                  我现在在哪个维度、坐标多少
/hub selftest               运行内置自检（管理/控制台）

/island menu                打开选岛界面
/island hub                 回空岛服大厅
/island classic             去经典空岛
/island ocean               去海岛
/island home                回上次那种岛
/island info                我的岛信息
/island reset <类型>        重置我的岛（含冷却与二次确认，清背包与地形，谨慎）

/trinket                    打开虚月饰品栏（也可用 B 键或背包左上角 ✦ 按钮）

/register <密码> <确认密码>  认证兜底注册
/login <密码>               认证兜底登录
```

权限节点只有三个：`hubsuite.admin`、`hubsuite.build.creative`、`hubsuite.island.admin`。

## 开发

```bash
./gradlew build                                  # 编译服务端与客户端
./gradlew runServer -Dhubsuite.selftest=15       # 起服并运行全量自检
./scripts/dev-server.sh "hub selftest"           # 快捷起服并跑自检
./gradlew :client:runClientAuto                  # 启动本地测试客户端
```

改完代码请务必跑一次 `hub selftest` —— 多世界隔离这类行为光看代码确认不了。

用 AI 协作开发请先读 [AGENT.md](AGENT.md)（工作约定、验收标准与踩坑记录）。
